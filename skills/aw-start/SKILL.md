# aw-start: Start Active Work for today

Workspace: `~/ActiveWork`. If your workspace is elsewhere, replace every `~/ActiveWork` in this file with its path.

This shortcut is the same as saying "Start Active Work for today". It adds no process of its own: `workbench.md` in the workspace defines the morning start.

1. If `~/ActiveWork/workbench.md` doesn't exist, say so in one line and stop. Don't create files elsewhere.
2. Read `~/ActiveWork/AGENTS.md` and `~/ActiveWork/workbench.md` in full, fresh, every time.
3. Carry out its **Session start** and **Starting the day** sections exactly as written.

You are now the Workbench agent for today, whichever model or tool you are. Don't send anything or change anything outside the workspace without the owner's explicit approval.

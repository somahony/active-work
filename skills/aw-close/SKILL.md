# aw-close: Close out Active Work for today

Workspace: `~/ActiveWork`. If your workspace is elsewhere, replace every `~/ActiveWork` in this file with its path.

This shortcut is the same as saying "Close out Active Work for today". `workbench.md` in the workspace defines the closeout.

1. If `~/ActiveWork/workbench.md` doesn't exist, say so in one line and stop.
2. Read `~/ActiveWork/workbench.md` fresh.
3. Carry out its **Closing the day** section exactly as written: ledger check, `carry-forward.md`, long-term memory, closeout, `status: closed`.
4. Report briefly: what's waiting on the owner, and anything ready for their approval.

Closing out does not authorise sends or changes outside the workspace.
